# Munro Law PLLC — website

Static site for munrolawpllc.com (tax, business & estate planning law firm in Seattle).

- Plain HTML/CSS/JS, no build step. Pages: index, services, team, contact, george, andrew.
- Hosted on GitHub Pages with the custom domain `munrolawpllc.com` (see `CNAME`).
- `gate.js` is a temporary client-side password gate for the draft-review period — delete it and the `<script src="gate.js">` tag in each page's `<head>` at launch.
- Contact form is not wired to a backend yet (see TODO in `main.js`).
